Construction notes

A QR should be boring infrastructure.

We mean that as a compliment. Once printed, your code should keep working without us.

  1. 01

    Your data stays here

    Generation, scan verification and batch ZIP creation all run locally. Open developer tools and watch: no payload request is sent.

  2. 02

    The payload is direct

    The code contains exactly the URL, Wi-Fi details, contact, event or text shown in the inspector—never our redirect.

  3. 03

    The file is yours

    SVG, PNG and PDF downloads have no expiry switch. Keep the destination online and the printed code keeps working.
